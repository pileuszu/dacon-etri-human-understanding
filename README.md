# ETRI 휴먼이해 인공지능 논문경진대회 (제5회)

이 저장소는 **제5회 ETRI 휴먼이해 인공지능 논문경진대회** 참여를 위한 데이터 분석 및 모델링 코드를 관리합니다.

## 📌 대회 개요
라이프로그 데이터를 활용하여 사용자의 수면 품질, 피로도, 스트레스 및 다양한 수면 지표를 예측하는 멀티모달 AI 모델을 개발합니다.

## 📂 프로젝트 문서 (Documentation)
대회와 관련된 상세 정보는 아래 문서들을 참고해 주세요.

1.  **[대회 개요 및 일정](docs/competition.md)**: 대회 배경, 주제 및 주요 일정 안내
2.  **[평가 규칙](docs/EVALUATION_RULE.md)**: 리더보드 평가 산식(Log-Loss) 및 단계별 평가 프로세스
3.  **[참여 및 제출 가이드](docs/PARTICIPATION_RULES.md)**: 팀 구성, 논문 투고 방법, 코드 제출 규칙 및 유의사항

## 🚀 시작하기
- `data/`: 대회 제공 데이터셋 (개인별 라이프로그)
- `notebooks/basic_eda/`: 번호순으로 정렬된 기초 EDA 및 실험용 Jupyter Notebooks
- `src/`: 모델 학습 및 추론용 소스 코드
