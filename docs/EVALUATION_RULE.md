# 대회 평가 규칙 (Evaluation Rules)

## 1. 리더보드 평가 산식
- **Metric**: Average Log-Loss
- **Public Score**: 전체 테스트 데이터 중 사전 샘플링된 44%
- **Private Score**: 전체 테스트 데이터 100%

## 2. 세부 평가 방식

### 1) 리더보드 평가 (Leaderboard)
- 리더보드 제출은 필수 참여 요건입니다.
- **Private 리더보드 공개**: 2026년 6월 26일 이후.
- **특전**: 상위 60팀에게 논문 작성 지원을 위한 Claude API 크레딧 제공.
- ※ 리더보드 성적은 최종 수상 순위에 직접 반영되지 않습니다.

### 2) 논문 평가 (Paper Evaluation)
- **대상**: ICTC 2026 Workshop Track (ETRI Human Understanding AI Paper Challenge 부문) 제출 논문.
- **규정**: [ICTC 2026](https://ictc.org/) 논문 작성 및 접수 규정 준수.
- **결과**: 채택(Accept) 또는 거절(Reject).
- **의무**: 채택된 논문은 반드시 ICTC 2026 학술대회에서 등록 및 발표(포스터 포함)해야 하며, 불참 시 게재가 취소됩니다.

### 3) 재현성 검증 (Reproducibility)
- 논문 채택 팀은 **코드 및 모델 설명서**를 제출해야 합니다.
- 검증 통과 실패 시 최종 평가 대상에서 제외됩니다.
- 규칙 탭의 '4. 코드 및 모델 설명서 제출 규칙'을 준수해야 합니다.

### 4) 종합 평가 (Comprehensive Evaluation)
- **대상**: 리더보드, 논문 평가, 재현성 검증을 모두 통과한 팀.
- **평가 요소**: 연구의 참신성, 기술적 완성도, 연구 분야 기여도 등.
- **최종 시상**: 상위 1~5위 팀 선정.
- **시상식**: 10월 15일(목) 발표 및 시상식 참여 필수 (최소 1인). 불참 시 수상 자격 박탈 가능.

---
**※ 필수 충족 조건**: 1) 리더보드 제출, 2) 논문 채택 및 발표, 3) 재현성 검증 통과
